Instruction quick reference

Contacts & coils

NO contact passes when bit = 1. NC contact passes when bit = 0. Coil writes the rung result to a bit. Set/reset are latched operations.

Timers

TON on-delay, TOF off-delay, TP pulse. S7 classic projects may also use S5 timers; time base and instruction syntax depend on CPU/STEP 7 version.

Program blocks

OB handles events/cycle; FC has no instance DB; FB uses instance data; DB stores global or instance data. Exact behavior depends on block interface and call.

Safe practice

Never bypass real E-stops, burner trips, permissives or safety relays. Test with isolated simulation and approved procedures.
